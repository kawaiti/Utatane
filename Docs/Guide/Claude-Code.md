# Claude Codeを操作する

ゴーストを通して、パソコン上のClaude Codeに指示を出す機能です。指示は文字入力のほか、ホットキーを押している間に話す音声でも出せます。進み具合と結果の要約はゴーストが話し、全文と詳細は専用ウィンドウに表示します。

ファイルの書き換えやコマンドの実行は、利用者が許可するまで行いません。許可の仕組みは「[承認](#承認)」を読んでください。

## 準備

- `claude`コマンド（Claude Code CLI）をインストールし、ログインを済ませてください。Utataneは`~/.local/bin/claude`、`/opt/homebrew/bin/claude`、`/usr/local/bin/claude`、`~/.claude/local/claude`の順に探します。見つからない場合や別の場所に置いている場合は、設定でパスを指定します。
- 「本体設定」→「Claude Code」で作業ディレクトリを選びます。Claude Codeはこのフォルダを作業場所として起動します。未選択のままでは起動せず、設定画面を開きます。
- メニューバーの「操作」→「Claude Code…」でウィンドウを開きます。下部の入力欄に指示を入力して送信します。

## 設定

「本体設定」→「Claude Code」にあります。

| 項目 | 内容 |
| --- | --- |
| 音声入力を有効にする | 既定はオフです。オフの間は、マイクと音声認識の許可を要求せず、ホットキーも登録しません。文字入力は音声入力がオフでも使えます。 |
| 復唱確認 | 既定はオンです。音声で聞き取った指示を読み上げ、「はい」と答えてから送ります。オフにすると、聞き取った指示をそのまま送ります。文字入力は復唱しません。 |
| ホットキー | 押している間だけ聞き取ります。`Control + Option + Space`、`右Option（長押し）`、`fn（長押し）`から選びます。 |
| claudeのパス | 既定は自動検出です。「選択…」で指定し、「クリア」で自動検出へ戻します。 |
| 作業ディレクトリ | Claude Codeを動かすフォルダです。 |
| モデル | 空欄ならClaude Codeの既定のモデルを使います。入力すると`--model`として渡します。 |
| 権限モード | 「確認しながら」または「編集を自動許可」。 |

ホットキーの動きは次のとおりです。

- `Control + Option + Space`: 3つのキーを同時に押した時点で聞き取りを始め、スペースキーを離すと終わります。
- `右Option`と`fn`: 約0.35秒押し続けると聞き取りを始め、離すと終わります。押している間に別のキーを打った場合は、聞き取りを始めません。通常の修飾キーとしての使い方は妨げません。

権限モードは、Claude Codeの`--permission-mode`へそのまま渡します。

- 確認しながら（`default`）: ファイルの編集やコマンドの実行のたびに、承認を求めます。
- 編集を自動許可（`acceptEdits`）: ファイルの編集はClaude Code側で自動的に許可します。コマンドの実行は引き続き承認を求めます。

設定を変えると、次の指示から反映します。作業中に設定を変えた場合、新しい設定での起動はいまの指示が終わるまで待たされ、その間に送った指示には「作業中です」と表示します。

## 指示の出し方

### 文字で出す

Claude Codeウィンドウの入力欄に入力して送信します。復唱はありません。作業中は「中断」ボタンで止められます。

### 声で出す

音声入力を有効にしたうえで、次の順に操作します。

1. ホットキーを押したまま、指示を話します。
2. キーを離すと、聞き取った内容をウィンドウに表示します。
3. 復唱確認がオンなら、ゴーストが「『…』と指示します。よろしいですか?」と読み上げます。「はい」で送信、「いいえ」で取りやめます。もう一度ホットキーを押して答えてください。
4. 作業が始まると、ゴーストが進み具合を話し、終わると結果を要約して話します。

指示を送ったあとも、次のように話しかけられます。

- 「止めて」「とめて」「中断」「ストップ」: 作業を中断します。
- 作業中に別の指示を話すと、ゴーストが「作業中です」と答え、その指示は送りません。
- 復唱や承認の返事を待っている間は、「はい」「いいえ」と中断の言葉だけを受け付けます。それ以外を話すと「聞き取れませんでした」と答え、指示としては扱いません。
- 返事を待っていないときの「はい」「いいえ」は、通常の指示として扱われます。

「はい」は「許可」「OK」「いいよ」「実行」なども、「いいえ」は「拒否」「だめ」「やめて」「キャンセル」なども同じ扱いです。音声認識は日本語（`ja-JP`）です。

Claude Codeには、日本語で3文以内に要約して答えるよう伝えています。詳しい内容はウィンドウで確認してください。

## 承認

Claude Codeがファイルの書き換えやコマンドの実行をしようとすると、ウィンドウに許可を求める表示が出て、ゴーストが内容を読み上げます。表示には、実際に実行されるコマンドやファイルのパスを示します。

- 読み取り専用のツール（`Read`、`Glob`、`Grep`、`LS`）は、確認なしで許可します。
- 書き込みや`Bash`などは、ウィンドウの「許可」「拒否」ボタンか、声の「はい」「いいえ」で答えます。
- `rm`、`sudo`、`dd`、`mkfs`、`git push`、`git clean`、`git reset --hard`、再帰的な`chmod`、`| sh`のようなシェルへのパイプなどは危険な操作として扱います。表示を赤くし、声の「はい」では許可できません。ウィンドウの「許可」ボタンだけで許可できます。「いいえ」は声でも通ります。
- 45秒以内に答えなかった場合は、拒否として扱います。中断した場合も拒否です。
- ホットキーを押している最中に許可の表示が出た場合、そのときの発話では答えられません。いったん離し、もう一度押して話してください。前の確認に対する返事が新しい確認へ届かないようにするための動作です。

### 注意

危険な操作の判定は、安全のための補助です。実行を隔離する仕組みではありません。次のような書き方は検出できないため、コマンドの中身をよく読んでから許可してください。

- `bash -c "rm -rf …"` のようにシェルへ文字列を渡す書き方
- `$(rm …)` のようなコマンド置換
- `xargs rm` のように別のコマンドへ渡す書き方

反対に、引用符の中の`;`や`&`などで、安全なコマンドを危険と判定することがあります。

## 必要な権限

- マイクと音声認識: 音声入力を有効にして初めてホットキーを押したとき、macOSが許可を求めます。許可しないと聞き取れません。音声入力がオフなら、どちらも要求しません。
- アクセシビリティ: 別のアプリを使っている間もホットキーを使うために必要です。音声入力を有効にしたとき、未許可ならウィンドウに案内を一度だけ表示します。「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」でUtataneを許可してください。未許可の間は、Utataneがアクティブなときだけホットキーが効きます。

## 開発ビルド（Debug）で使う

承認の中継には、補助プログラム`utatane-mcp`を使います。リリースビルドではアプリ内（`Contents/Helpers`）に同梱しますが、Debugビルドには同梱しません。補助プログラムが見つからない間は、承認を経由せずにClaude Codeが動くことがないよう、起動を取りやめます。「承認用のヘルパーが見つかりません」と表示されます。

Debugビルドで試すには、補助プログラムをビルドし、環境変数`UTATANE_MCP_PATH`に指定してUtataneを起動します。

```sh
swift build --package-path packages --product utatane-mcp
UTATANE_MCP_PATH="$PWD/packages/.build/debug/utatane-mcp" open -a Utatane
```

Xcodeから実行する場合は、スキームの環境変数へ同じ値を設定してください。

## 制限

- 同時に動かせるセッションは1つです。作業中は新しい指示を送れません。
- 音声認識はmacOS標準のエンジン（日本語）のみです。ほかのエンジンは選べません。
- 承認の要求は同時に1件だけ扱います。
- Claude Codeの出力形式と承認の応答形式は、公式ドキュメントの記述に基づいて実装しています。実機での全項目の確認は済んでいません。`claude`の更新で動作が変わる可能性があります。
